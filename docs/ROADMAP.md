# RAVEN Roadmap

## M0 — Foundation
- Monorepo, deterministic runtime, scheduler, telemetry, ADRs.

## M1 — Renderer
- WebGL2 capability probe, resource registry, render graph, scene extraction, dynamic resolution.

## M2 — World Runtime
- Sector streaming, world fields, HLOD contracts, deterministic persistence.

## M3 — Procedural Asset Compiler
- Mesh builder, hard-surface profiles/lofts, implicit surface hooks, runtime baking, LOD generation contracts.

## M4 — Materials & Surfaces
- Layered material graphs, procedural texture jobs, surface state, wetness/dirt/damage masks.

## M5 — Character Runtime
- Skeleton, pose buffer, constraints, IK/contact solver, procedural motion field interfaces.

## M6 — Atmosphere & Effects
- Shared wind/moisture/light fields, volumetric approximation, surface-aware effects.

## M7 — Optimization
- HLOD, projected-size budgets, animation LOD, job throttling, watchdog and adaptive quality.

## M8 — RAVEN Lab
- A tiny technical validation scene. It is not a game and exists only to prove engine subsystems.
