# Procedural topology

RAVEN architecture and hard-surface generation is based on topology-producing operations rather than visible primitive stacking.

The foundation now includes:
- ear-clipped triangulation for simple concave polygons;
- arbitrary footprint extrusion;
- facade tessellation around real rectangular openings;
- reveal surfaces that give openings physical depth;
- whole-building shell generation from footprint edges;
- optional structural floor slabs;
- mesh merge, transforms and normal reconstruction;
- loft-based hard-surface generation.

A window generated by `compileFacade` is absent wall topology plus reveal surfaces; it is not a dark rectangle placed in front of an intact wall.
